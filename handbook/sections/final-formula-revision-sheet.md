## Final formula revision sheet

| Topic | Formula |
|---|---|
| HCF–LCM | $\operatorname{HCF}(a,b)\operatorname{LCM}(a,b)=ab$ |
| Quadratic zeros | Sum $=-b/a$; product $=c/a$ |
| Linear pair | Compare $a_1/a_2,b_1/b_2,c_1/c_2$ |
| Quadratic roots | $(-b\pm\sqrt{b^2-4ac})/(2a)$ |
| AP | $a_n=a+(n-1)d$; $S_n=\frac n2[2a+(n-1)d]$ |
| Similar triangle area | Area ratio is square of corresponding-side ratio |
| Distance / section | $\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$; weighted coordinates over $m+n$ |
| Trigonometry | $\sin^2A+\cos^2A=1$ |
| Circle | $C=2\pi r$; $A=\pi r^2$ |
| Sector | Arc $=(\theta/360^\circ)2\pi r$; area $=(\theta/360^\circ)\pi r^2$ |
| Solids | See Chapter 12 formula table; check exposed surfaces |
| Statistics | Mean $\sum f_ix_i/N$; grouped median and mode formulas in Chapter 13 |
| Probability | $P(E)=n(E)/n(S)$; $P(E')=1-P(E)$ |
